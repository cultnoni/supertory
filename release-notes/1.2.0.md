# SuperTory 1.2.0

## 신규

- **바인더 폴더 무제한 중첩** — 부·장을 폴더 안에 폴더로 자유롭게 쌓아 올릴 수 있습니다 (깊이 제한 없이 구성)
- **폴더 우클릭 메뉴** — 색상 표시, 북마크, 상단 고정, 박스로 묶기 등 표시·정렬 옵션
- **실행 취소 / 다시 실행** — 폴더 만들기·버리기·이동·이름 바꾸기·색상·박스·고정·순번 정리까지 되돌리거나 다시 적용
- **회차 우클릭 이름 바꾸기** — 더블클릭 대신 우클릭 메뉴로 제목 수정을 통일

## 개선

- **공지·이벤트 팝업** — 「다시 보지 않기」로 현재 안내를 닫아 두면, 같은 내용은 다시 뜨지 않습니다 (새 공지·이벤트 버전이 나오면 다시 안내)
- **웰컴 화면 시작 안내** — 「여기서 시작!」 박스에 은은한 광택 효과를 더해 눈에 잘 띄도록 개선
- **우클릭 메뉴 통일** — 회차·폴더·기능 버튼 메뉴의 레이아웃과 글자 스타일을 맞춤
- **「이 기능 숨기기」** — 우클릭으로 감춘 버튼·표시가 화면에서 제대로 사라지도록 수정
