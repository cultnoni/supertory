# SuperTory 1.3.6

## 신규

- **문서 불러오기 씬 구분** — 빈 줄 개수, `#` / `***` / `---` 표식, 직접 입력한 구분선으로 씬을 나눌 수 있습니다. 웹소설처럼 한 줄만 띄운 문단은 같은 씬으로 남깁니다.
- **불러오기 후 인물 자동 분석** — 토리가 등장인물을 찾아 빈 설정 칸만 채웁니다. 이미 적어 둔 칸은 덮지 않고 「새 분석 있음」 뱃지로 보여 줍니다.
- **불러오기 후 세계관 자동 분석** — 무대·특이점·극단 요소·사회·세력 13칸을 같은 원칙으로 채웁니다.
- **가상 독자 1:1** — 소통방에서 독자 페르소나를 고른 뒤 대화를 시작합니다. 전체보기로 소개를 펼칠 수 있습니다.
- **내 캐릭터와 대화·시뮬레이션** — 설정집 인물과 이야기하거나, 여러 명을 골라 상황을 시뮬합니다. 목록에도 전체보기가 있습니다.
- **글럼프 응급실** — 도구별 토리 애니, 번아웃 딴짓, 공통 종료 화면을 맞췄습니다.

## 개선

- **목차 폴더 색** — 쨍한 색 팔레트와 본문 우클릭 편집 메뉴를 정리했습니다.
- **작명소** — 무협 용어를 보강하고, 토리 대화 아이콘 툴바를 맞췄습니다.
- **인물 저장** — 캐릭터 시트 저장 버튼 위치를 첫 화면 배치와 함께 맞췄습니다.

## 수정

- **무료 티어 쿼터** — 인물 분석 다음에 세계관을 이어 호출해, Gemini 호출이 한 번에 몰리지 않게 했습니다. 실패해도 불러오기 자체는 막지 않습니다.
