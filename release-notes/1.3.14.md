# SuperTory 1.3.14

## 신규

- **첨삭 피드백** — 토리 패널에서 Claude 기반 첨삭을 돌립니다. 단편·장편·중간 점검 파이프라인, 리포트와 카드, 카드에 질문하기를 포함합니다.
- **일반문학 첨삭** — 루브릭·장면 지도·버전 비교와 교정 카드를 작품 단위로 이어받습니다. 판정과 비교를 분리해 이전 리포트가 새 판정에 섞이지 않게 했습니다.
- **처음부터 다시 보기** — 이전 첨삭 카드를 이어받지 않고 새로 선별할 수 있습니다.
- **넓은 패널** — 첨삭 검토·선택하기 결과를 작성 중 화면 옆 넓은 패널에서 엽니다.
- **쪽쓰기** — 조판 오버레이와 프리셋 선택, 서식 회차 진입 가드를 정리했습니다.
- **본문 구분선** — 우클릭으로 스타일·정렬과 재사용 프리셋을 둡니다.

## 개선

- **타이틀바·패널 chrome** — 로고·고정핀·설정집 아이콘과 좌우 패널 여백을 맞췄습니다.
- **목차** — 어떤 폴더에서든 회차·하위폴더를 추가하고, 빈 폴더 버튼을 정리했습니다.
- **웰컴** — 자매 앱 카드와 마스코트 뱃지를 다듬었습니다.
- **장르문학** — 로맨스 메인 장르와 BL/로맨스 참조 태그를 보강했습니다.

## 수정

- **첨삭 이어받기** — 바뀌지 않은 문단의 open 카드는 재선별하지 않고, 근거 인용이 하나라도 사라지면 이전 판정을 유지하지 않습니다.
- **의도 대조** — 기획의도·문체 5번과의 일치는 선별 모델이 판정하고, 키워드는 보조로만 씁니다.
- **개발/패키지 포트** — 로컬 서버와 설치본이 서로 종료하지 않게 포트를 분리했습니다.
- **백엔드 로그** — 크래시 로그와 버퍼링을 보강해 설치본에서도 원인을 남깁니다.
- **뷰어·조판** — 저장·미리보기 탭과 안내 문구를 정리했습니다.
