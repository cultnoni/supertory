# SuperTory 1.3.7

## 신규

- **가상 독자 토론** — 소통방에서 독자 페르소나들이 순차적으로 토론하는 패널을 붙였습니다.
- **한·영·스페인어** — 화면 문구를 로케일로 옮기고, 뷰어 목차 점프·알림·토스트가 선택한 언어에 맞게 나옵니다.
- **글자수 목표 전체 적용** — 목표/저장을 우클릭하면 전 회차에 적용할 수 있습니다.

## 개선

- **목차** — 하위 원고 기본 이탤릭·연결선·작성상태 정렬을 맞추고, 루트 +폴더는 하나만 만들며 상자 폴더에도 원고를 옮길 수 있습니다.
- **앱 아이콘** — 설치·바로가기 아이콘을 맞췄습니다.

## 수정

- **설정집 스크롤** — 세계관 등 입력 칸에 글자를 칠 때 화면이 맨 위로 튕기거나, 긴 칸 아래 내용이 위로 접히던 문제를 고쳤습니다.
