# SuperTory 1.3.3

## 신규

- **타자기 모드** — 아이콘바에서 켜면 입력 줄을 화면 중앙에 부드럽게 고정하고, 현재 줄에 은은한 하이라이트를 표시합니다.
- **기본 테마 Clean White & Deep Charcoal** — 쨍한 블루 대신 딥 차콜·쿨그레이로 명암 대비를 살린 기본 UI 크롬입니다.
- **모래사장 테마** — 이전 연베이지·오트밀 톤을 테마 선택에서 그대로 쓸 수 있습니다.

## 개선

- **웰컴 시작 안내** — 작품 시작하기 · 회차 쓰기 · 토리와 함께 쓰기 · 유용한 팁 문구를 다듬었습니다.
- **도우미 패널** — 직접요청 / 선택하기 / 결과보기 세그먼트와 입력·결과 칸 높이를 맞추고, 선택 칩·활성 탭 스타일을 정리했습니다.
- **아이콘바** — 가운데 구분선 제거, **분석 → 북마크 → 타자기** 순서로 배치했습니다.
- **단어찾기** — 아이콘바 버튼은 빼고, 본문 드래그 후 우클릭으로만 사용합니다.

## 수정

- **세그먼트 탭** — 선택 상자 왼쪽 테두리가 흐리게 보이던 문제와, 활성 색을 서식바 호버 톤에 맞게 조정했습니다.
- **선택하기 라디오 칩** — 글자가 위로 뜨던 세로 정렬을 가운데로 맞췄습니다.
