# SuperTory 1.1.0

## 신규

- **토리와 새 무대를 찾아요** (도우미 카테고리, 준비중)
  - 영상 각본으로 바꾸기
  - 오디오북 낭독 대본으로 바꾸기
  - 다국어 번역하기  
  클릭 시 기능 소개만 안내하며, 실제 변환은 곧 제공 예정입니다.
- **흥행 공식** — 참고 작품 분석, 프로필 저장, 작품에 연결, 회차 피드백·참고에 활용
- **프로젝트 인덱스** — 회차 요약과 작품 누적 맥락을 모아 토리가 설정·줄거리를 더 일관되게 참고
- **문서 가져오기 계층 인식** — 목차·부/장/화 구조를 반영해 바인더에 정리
- **떡밥 모음** — 원고에 심은 단서를 DB에 보관하고, 회수 시점 알림·미루기 지원
- **설정집 확장** — 작가 지침(토리 우선 지시), 줄거리 개요, 캐릭터 초상 사진 등

## 개선

- **투고·공모전용 시놉시스** — 설정한 글자 수 제한을 넘기면 결과 영역에 초과 경고 표시
- **설정집 펼침 상태** — 작품마다 마지막으로 연 설정 폴더를 따로 기억
- **한글(HWPX) 내보내기** — 패키지 생성 경로를 다듬어 한글에서 더 안정적으로 열리도록 개선

## 수정

- **한글(HWPX)·워드(DOCX) 내보내기** — 문단 사이 빈 줄(`엔터` 두 번)이 사라져 대화·장면 전환이 다닥다닥 붙던 문제 해결
