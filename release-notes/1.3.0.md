# SuperTory 1.3.0

## 신규

- **토리 도우미 회차 선택 팝업** — 회차 요약, 설정 붕괴 감지기, 중복 체크, 다음 아이디어 제안, 브레인스토밍, 피드백 요청에서 현재 회차뿐 아니라 다른 회차·여러 회차를 지정해 실행할 수 있습니다
- **이어서 쓰기 전개 방향 초안** — 한 번 실행으로 후킹형·전개형·전환형 세 가지 스타일을 동시에 받아 비교할 수 있습니다
- **이어서 쓰기 분량 세분화** — 짧게·중간·길게·장면까지·자동 조절 옵션

## 개선

- **도우미 팝업 디자인 통일** — 제목·안내문·버튼 스타일을 정리했습니다
- **다중 회차 요청 통합** — 여러 회차 선택 시 개별 호출 대신 한 번의 요청으로 처리해 응답 속도를 개선했습니다
- **설정 붕괴 감지기 판정 보강** — 서술자 시점과 인물 시점을 구분해 캐릭터 일관성을 더 정확히 봅니다
- **문장 다듬기 분량 안내** — 과도하게 긴 구간을 선택했을 때 안내를 띄웁니다
- **안내 문구 정리** — 중복 표현을 줄이고 문장을 다듬었습니다

## 수정

- **다중 회차 선택 목록 레이아웃** — 회차 제목이 깨져 보이던 문제를 고쳤습니다
- **도우미 팝업 캐시** — 최신 화면 변경이 반영되지 않던 문제를 고쳤습니다
