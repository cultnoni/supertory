# SuperTory 디자인 지침 — 섬과 종이 (Island & Paper)

화면을 새로 만들거나 고칠 때, 기능을 추가할 때 **이 문서를 기준**으로 합니다.
살아 있는 시안: `web/dev/main-design-v4.html` (브라우저에서 `/dev/main-design-v4.html`). 구현 레이어: `web/island.css` (`styles.css` 뒤에 로드).

---

## 1. 원칙

1. **섬**: 화면은 둥근 카드(섬) 여러 개가 바깥 여백(gutter) 위에 떠 있는 구조다. 섬끼리는 선·그림자·여백으로만 나눈다.
2. **종이**: 원고는 책상(연한 회색) 위에 놓인 종이다. 도구는 종이 밖(패널색 띠)에 둔다. 종이만 페이지 테마색(`--page-*`)을 쓴다.
3. **한 줄 우선**: 도구는 이름(라벨)과 함께 **한 줄에 모두** 보여야 한다. 모자라면 뒤쪽부터 기존 `» 더보기`로 접는다. 줄바꿈·라벨 잘림(…)·겹침 금지.
4. **기능은 허공에 두지 않는다**: 시안/개편에서 안 보이는 기능도 반드시 §7 배치 지도의 한 곳에 둔다(팝오버, 더보기, 도크 레일, 설정). 새 기능은 만들기 전에 어디에 둘지 먼저 정한다.
5. **조용한 색**: 강조색(`--accent`)은 현재 상태·주요 버튼 하나에만. 장식용 색 금지.
6. **원고 안전 우선**: 디자인 때문에 autosave·로컬 초안 로직(AGENTS.md "Manuscript safety")을 건드리지 않는다. 스타일 변경은 CSS가 기본이고, 마크업을 바꿔도 **id·data-속성은 유지**한다.

## 2. 토큰

색은 **기존 테마 변수만** 쓴다(테마 12종·다크 호환). 새 토큰은 `--isl-*`.

| 용도 | 변수 | 비고 |
|---|---|---|
| 바깥 여백·타이틀바 | `--chrome-bg` | 기본 라이트는 `#ecebe8`로 한 단계 어둡게 |
| 섬(패널) 바탕 | `--panel` | |
| 책상 | `--isl-desk` | `--chrome-bg`보다 약간 어두움 |
| 눌림·세그먼트 바탕·입력 바 | `--isl-sunk` | |
| 선 | `--line` | 1px |
| 본문 글자 / 보조 / 흐림 | `--text-primary` / `--isl-ink2` / `--isl-ink3` | |
| 강조 | `--accent` | 연한 배경은 `color-mix(in srgb, var(--accent) 12%, var(--panel))` |
| 종이 | `--page-editor-bg`, `--page-ink` | 페이지 테마 |

**포인트 색(베이지·회녹) — 목차 기준.** 목차(바인더)에서 쓰는 연한 색을 앱 전체의 포인트로 통일한다. 진한 초록·갈색 테두리·푸른 기가 도는 선택색을 따로 쓰지 않는다. 값은 기본 라이트 테마 기준이며, 구현은 고정 색이 아니라 테마 변수에서 섞어 쓴다(다른 테마에서도 목차와 같은 결).

| 용도 | 기본 라이트 값 | 구현 |
|---|---|---|
| 베이지(안내 박스·세그먼트 바탕·칩) | `#f3f2f1` | `--isl-sunk` 계열 |
| 회녹(아이콘·체크박스 채움·폴더 아이콘) | `#859892` | `--accent`를 `--muted`와 섞어 낮춘 색 |
| 선택된 줄(현재 회차 줄과 같음) | `#eef0f2` | `--isl-sunk` |
| 주요 버튼 | 앱 공통 주요 버튼 그대로(`--accent` 채움). 화면마다 하나만. 옵션 화면 하단도 같다 | `.modal-card .primary` |
| 선택된 칩 | 회녹 20% 바탕 + 진한 회녹 글자 + 회녹 선 | `color-mix(in srgb, <회녹> 20%, var(--panel))` |
| 상태 점 | 완성 `#6a997f` · 초안 `#c5a663` | `--isl-st-*` |

간격·모양: 섬 사이 `--isl-gap: 8px`, 섬 반경 `--isl-r: 14px`, 작은 요소 `--isl-r-sm: 9px`, 그림자 `--isl-shadow`(섬) / `--isl-pop-shadow`(팝오버). 패널 폭은 좌우 **동일** `--isl-panel-w: 292px`.
글꼴: UI는 Pretendard(`--font-ui`), 원고는 `--font-editor`.
스크롤바: 8px, 연한 반투명(전역). 개별로 진하게 만들지 않는다.

## 3. 레이아웃

```
타이틀바(40px): [마스코트=시작 화면][새로 만들기][관리자][테마][배경음][짓시]   (가운데) 검색 알약   [… 창 컨트롤 자리는 비움]
┌ 바인더 섬 ┐ ┌ 가운데 섬(책상) ──────────────┐ ┌ SuperTORY 섬 ┐
│ 작품 목록▾ │ │ 열린 회차 탭                   │ │ ◫ [마스코트]SuperTORY │
│ 본문|설정집 │ │ 제목줄(‹이전 ✨제목 다음›)    │ │ 체크|대화|도구|위젯     │
│ …          │ │ 아이콘 도구줄(이름 포함 13개) │ │                        │
│            │ │ 서식줄 · 상태/요약 줄          │ │ 토리 알림              │
│            │ │ [종이]                          │ │                        │
└────────────┘ └────────────────────────────────┘ └────────────────────────┘
```

- 타이틀바 오른쪽 끝은 OS 창 컨트롤(최소화·최대화·닫기) 영역이다. **그 자리에 아무것도 두지 않는다.**
- 섬을 접으면 자리를 비운다. 왼쪽 섬은 완전히 접히고(설정에서 켜면 44px 회차 번호 미니 내비만 남음), 오른쪽 섬은 0px로 접히며 레일은 숨긴다 — 접힌 오른쪽 섬은 떠 있는 마스코트 배지(`.isl-ai-badge`)로 다시 연다. 위젯 레일(`.isl-rail`)은 SuperTORY `위젯` 탭 안에 있다.
- 접기 버튼: 왼쪽 섬은 섬 오른쪽 위, **오른쪽 섬은 섬 왼쪽 위**. 섬 제목은 가운데 정렬.
- 창이 좁아지면 아이콘 도구줄은 `» 더보기`로(§4 아이콘 도구), 오른쪽 섬이 먼저 접힌다.
- **넓은 패널(옵션 화면·첨삭 검토)**: 선택하기에서 옵션을 고르면 왼쪽 섬이 닫히고 오른쪽 섬이 `clamp(420px, 40vw, 640px)`로 넓어진다. 호스트(`#feedbackReviewHost`)가 곧 섬이다 — 오른쪽은 창 벽에 붙고 왼쪽만 둥글며, 안쪽 카드는 테두리·그림자 없이 내용만(2중 상자 금지). 닫으면 두 섬이 원래 폭으로 돌아온다. 머리글의 크기 전환으로 `작은 창`(떠 있는 위젯)과 오갈 수 있고, 그 선택은 `supertory.widePanel.chrome`에 기억한다(화면이 좁거나 분할·집중·타자기라서 억지로 작은 창이 된 경우는 기억하지 않음).

## 4. 부품

| 부품 | 규칙 |
|---|---|
| 아이콘 도구 | 아이콘(15px) + 이름 가로 배치, 12.5px, 패딩 6×7. 보통=`--isl-ink2`, hover=`--isl-sunk` 바탕, 활성=accent 12% 바탕+accent 글자. **이름은 짧게**(예: 메모·인물·자료). |
| 서식줄 | `--isl-sunk` 둥근 바. 자주 쓰는 것만 앞에, 나머지는 `더보기` 팝오버(장평·색·글머리·특수문자·전체 적용). |
| 세그먼트 탭 | `.seg-control` — 바탕 `--isl-sunk`, 활성 탭은 `--panel` + 약한 그림자. |
| 이전/다음 회차 | **박스 없는** 글자 버튼, 제목 양옆. 아이콘 도구줄에 넣지 않는다. |
| 팝오버·메뉴 | 반경 14, `--isl-pop-shadow`, 아이콘+이름+보조 설명(오른쪽 흐린 글자). 같은 앵커의 메뉴는 한 번에 하나만. |
| 설정집 메인 보드 | `#workArea` 직계 보드(캐릭터·아이템·사전·생각수첩·키워드·세계관·떡밥/수집창고 모음·소개/로그라인 문서·설정 검색)는 **같은 틀**: 여백 20×28, 책상 위 투명 바탕, 제목 22px/700. 새 보드를 만들면 `island.css`의 보드 공통 선택자 목록에 추가한다. 카드는 `--panel` + `--line` + 반경 12. |
| 모달 | 반경 14~16, 헤더 우측 닫기, 하단 버튼은 오른쪽 정렬(취소=고스트, 확정=accent). 화면을 상시 가리는 모달 금지 — 기록·알림류는 팝오버/섬 안에서. |
| 입력 | `--isl-sunk` 또는 `--panel`+`--line`. placeholder는 포커스에서 숨기지 않는다. |
| 칩·태그 | 반경 6, 11~12px. 의미 색: 문장=accent, 떡밥=경고색, 맞춤법=파랑 계열(테마별 대응). |
| 마스코트 | **이모지·한 글자 대체 금지.** `/assets/tori-mascot.png`만 쓴다. 쓰는 곳: 타이틀바 시작 화면 버튼, SuperTORY 머리글, 토리 알림·대화 머리글, 빈 화면. 작품 목록 아이콘에는 쓰지 않는다(라이브러리 아이콘 `library-big`). |
| 선택하기 옵션 화면 (넓은 패널 `.is-wide-panel-card`, 열리는 방식은 §3) | 회차 요약·피드백 받기·중복 체크·아이디어·브레인스토밍·설정 확인·템포 분석 등은 **같은 틀**: 머리글 `[아이콘 칩 + 제목 + 크기 전환 + ×]` → 베이지 안내 박스 한 줄 → 입력 영역마다 작은 흐린 라벨 → 세그먼트·칩·체크 줄 → 하단 `보조 설명(왼쪽) + 주요 버튼 하나(오른쪽, 앱 공통 `--accent` 채움)`. 선택한 항목은 목록 안의 선택 줄로 보이고 하단에 큰 굵은 제목으로 따로 쓰지 않는다. 색은 §2 포인트 색만. 글자 굵기는 400/500. |
| 아이콘 | 선 아이콘, stroke 1.8~2, `currentColor`. 새 아이콘은 같은 스타일(lucide)에서. |

## 5. 집필 화면

- 순서(위→아래): 열린 회차 탭 → 제목줄 → 아이콘 도구줄 → 서식줄 → 작성 상태·요약 → 종이.
- 제목줄: `‹ 이전 회차`(흐림) · `✨ 소제목 추천` + 제목 · `다음 회차 ›`. 탭줄 오른쪽의 `+`(다음 회차 탭 열기)는 **삭제됨** — 다시 만들지 않는다.
- `기록` 도구(타이머·집필 기록)는 아이콘줄에 두되, 클릭 한 번=시작/정지, 상세(달력·집계·설정·폰 연동)는 팝오버/모달.
- 종이는 가운데 정렬, 최대 폭 820px, 반경 4px, 얇은 링 그림자. 바깥 책상색은 `--isl-desk`.

## 6. SuperTORY 섬

- 머리글: `[접기] [마스코트 SuperTORY] ·` — 제목 가운데.
- 탭은 `체크 · 대화 · 도구 · 위젯` 4개(`.seg-control`). 한 화면에 탭 2단 이상 쌓지 않는다. `대화`는 토리·내 캐릭터·가상 독자 중 상대를 고르는 허브, `도구`는 `직접요청 · 선택하기 · 결과보기` 세그먼트(선택하기가 옵션 화면 목록), `위젯`은 도크 위젯 타일 레일.
- **체크 탭**(`#aiCheckView`): 집필 기록 카드(오늘 글자수·시간·목표 + 최근 7일 막대, `달력 ›`으로 기록 모달) + 실시간 토리 체크 카드. 위젯 본체(타이머·토리 체크·맞춤법·글자수)는 기존 도크 플로팅 위젯이고, 카드의 버튼이 같은 도크 항목을 연다 — 위젯 로직을 복제하지 않는다.
- **토리 알림**: 머리글 오른쪽 종 아이콘(미해결 개수 배지) → 섬 위에 뜨는 팝오버(`#toryNotifyBox.is-popover-open`). 큰 창으로 열기·알림 만들기가 팝오버 안에서 바로 닿아야 한다. 접힌 레일에는 종 버튼이 있고 누르면 패널을 펴서 팝오버를 연다. 바깥 클릭·Esc로 닫는다.
- 비용이 드는 기능은 버튼/카드에 도토리 비용을 같이 표시한다.

문학에서도 회차 요약·떡밥·복선 탐색기·설정 붕괴 감지기는 보인다(2026-10-22). 숨긴 기능은 선택하기 목록·소통방 카드·설정집 박스에서 함께 사라지고, 키워드 보드는 프리셋 대신 직접 입력으로 바뀐다.

## 8. 구현 규칙

- 스타일은 `web/island.css`에 쓴다. `styles.css`에는 새 디자인 규칙을 추가하지 않는다(기존 규칙을 덮어쓰는 것은 `island.css`에서 같은 선택자 + `!important`).
- 색을 직접 쓰지 않는다(그림자·반투명 오버레이 제외). 테마를 바꿔 보고 확인한다(기본·다크·최소 1개 텍스처 테마).
- 사용자에게 보이는 문구는 `ko/en/es` 3개 언어에 같은 키로. 새 키 접두어: 디자인 개편 관련은 `island.`.
- 변경 후: `node --check web/app.js`, `npm run lint:web`, `python -m unittest discover -s tests`, 기본 1440×900과 좁은 창(~1100)에서 한 줄/겹침 확인.

## 9. 적용 현황

- 적용(1단계): 섬 쉘·타이틀바 검색·아이콘 도구줄·종이·세그먼트 탭·SuperTORY 머리글(마스코트)·스크롤바·기본 라이트 팔레트(따뜻한 오프화이트 + 먹색).
- 적용(2단계): SuperTORY `체크` 탭(집필 기록 카드 + 7일 그래프, 토리 체크 바로가기).
- 적용(3단계): 토리 알림 → 머리글 종 팝오버. 텍스처·어두운 테마 13종 점검(서식·상태 띠는 페이지 바탕색을 유지해 대비 확보).
- 적용(4단계): 설정집 메인 보드 공통 틀, 모달 공통 부품(반경·버튼·입력), 메뉴/팝오버 공통 모양, 메모 칩이 있을 때 검색 알약이 비켜 서기.
- 적용(5단계, 2026-10-22): 전체 화면 점검 후속 — 튜토리얼 앵커, 옵션 화면 제목·세그먼트 한 줄, 모달 안내 박스 베이지, 교정본 카드·토리 체크 색, 글럼프 응급실 선 아이콘, 글자수 위젯 기본 닫힘·창 크기 따라가기, 넓은 패널 한 겹 상자, 기본 언어 한국어.
- 남음: 메모 표시줄 위치, 실시간 체크 결과를 패널 안에서 직접 보기(도크 위젯 재호스팅 필요), 교정·교열 비교 보고서 카드 색(머티리얼 고정색), 텍스처 테마(비밀 서재·추억 교실)의 비활성 세그먼트 대비.

## 10. 시안 대조 기준값 (main-design-v4 ↔ 실제 앱)

2026-10-15 적용 기준은 사용자 지정 시안 `web/dev/main-design-c-variations.html#c1`이다. 기본 테마는 C1의 회색·청록 팔레트, 왼쪽 272px / 오른쪽 304px, 종이 최대 760px / 안쪽 여백 52×72×80px을 쓴다. 다른 테마와 사용자가 저장한 패널 폭·원고 서식은 유지한다. 단일 집필 화면은 기존 `manuscriptPage` 스크롤 호스트 안의 `.isl-paper-sheet`에 경로·제목·상태·본문을 함께 배치한다. 분할 보기에서는 `setupIslandPaperLayout()`이 각 노드를 원래 위치로 돌려놓는다. 아래 이전 기준값보다 C1 시안 값이 우선한다.
