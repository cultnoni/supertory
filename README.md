# SuperTory 사용법

이 폴더는 내 컴퓨터에서만 쓰는 작은 글쓰기 앱입니다. 인터넷에 글을
올리거나 다른 사람에게 보내지 않습니다.

## 처음 열기

1. 이 폴더에서 `start_supertory.bat` 파일을 **두 번 클릭**합니다.
2. 잠시 후 인터넷 브라우저가 열립니다.
3. 첫 화면의 **새 작품 만들기**를 눌러 제목과 작품 종류를 입력합니다.
4. 왼쪽의 **+ 챕터**, **+ 씬**을 눌러 글의 뼈대를 만듭니다.
5. 씬을 누르고 가운데 큰 칸에 글을 쓴 뒤 **저장하기**를 누릅니다.
6. 오른쪽의 **+ 캐릭터**를 눌러 인물 정보를 적습니다.

## 작품 파일 (.stg) — 스크리브너처럼 더블클릭으로 열기

스크리브너가 작품마다 `.scriv` 프로젝트 파일을 두는 것처럼, SuperTory는 작품마다
`projects` 폴더에 **`작품이름.stg`** 파일을 만듭니다.

예: 작품 제목이 `선밖에서`이면 → `projects\선밖에서.stg`

1. **새 작품 만들기** 또는 **문서 가져오기**를 하면 `.stg` 파일이 자동 생성됩니다.
2. 탐색기에서 그 파일을 **더블클릭**하면 SuperTory가 해당 작품으로 열립니다.
3. 앱 안의 **작품 파일 위치** 버튼을 누르면 그 파일이 있는 폴더가 열립니다.

앱을 한 번 실행하면 Windows에 `.stg` 연결이 등록됩니다. 연결이 안 되면
`start_supertory.bat`을 한 번 실행한 뒤 다시 더블클릭해 보세요.

> 글 내용 자체는 안전하게 `data\supertory.sqlite3`에 저장됩니다.
> `.stg` 파일은 “이 작품을 연다”는 손잡이(스크리브너의 프로젝트 아이콘) 역할입니다.

## 외부 문서 가져오기

워드·한글·텍스트 등 이미 써 둔 글을 SuperTory로 옮길 수 있습니다.

1. 맨 위의 **문서 가져오기**를 누릅니다.
2. 파일을 고릅니다.
3. **작품 목적**(소설, 에세이, 논문, 자서전, 정보 전달 등)을 고릅니다.
4. 어디에 넣을지 고릅니다.
   - **새 작품으로 만들기**
   - **현재 작품에 새 챕터로 넣기**
   - **현재 작품의 챕터에 새 씬으로 넣기**
   - **지금 열린 씬에 덮어쓰기**
5. 글을 나누는 방식을 고릅니다.
   - **자동** — 목차가 있으면 목차, 없으면 제목, 그것도 없으면 통째로
   - **목차대로** — 글 앞의 목차/차례 항목마다 챕터 생성 (들여쓴 항목은 씬)
   - **제목마다** — `# 제목`, `제1장` 등
   - **빈 줄마다** / **통째로**
6. **가져오기**를 누르면 왼쪽 목차에 반영됩니다.

### 작품 목적(카테고리)

| 종류 | 설명 |
|------|------|
| 소설 | 장편·중편 이야기 |
| 동화 | 어린이·동화 이야기 (그림 위 글 상자 지원) |
| 단편 | 짧은 이야기 |
| 에세이 | 수필·감성 산문 |
| 정보 전달 | 논픽션·안내·지식 글 |
| 논문 | 학술·리포트 형식 |
| 자서전·회고록 | 개인 삶·기억 |
| 시 | 운문 |
| 시나리오·희곡 | 대본 |
| 일기·기록 | 일지·메모 모음 |
| 보고서 | 업무·조사 보고 |
| 칼럼·비평 | 의견·리뷰 |
| 기타 | 위에 없는 경우 |

### 지원 형식

| 형식 | 확장자 | 비고 |
|------|--------|------|
| 텍스트 | `.txt`, `.md`, `.csv` | UTF-8, 한글(CP949) 등 자동 인식 |
| Word | `.docx` | 권장 |
| 한글 | `.hwpx` | 한글 2014 이후 HWPX |
| 오픈도큐먼트 | `.odt` | LibreOffice 등 |
| 기타 | `.rtf`, `.html`, `.epub` | 서식은 단순 글자로 변환 |

**아직 바로 못 여는 형식**

- `.hwp` → 한글에서 HWPX 또는 DOCX로 저장
- `.doc` → Word에서 DOCX로 저장
- `.pdf` → 텍스트나 Word로 저장

파일 크기는 약 15MB까지입니다. 글은 이 컴퓨터의 `data` 폴더에만 저장됩니다.

## 왼쪽 목차(바인더)

- 긴 챕터·씬 제목은 바인더 안에서 `...` 으로 줄여 표시됩니다. 마우스를 올리면 전체 제목을 볼 수 있습니다.
- 목차 오른쪽 경계를 끌어 **너비를 조절**할 수 있습니다. (이 컴퓨터에 기억됩니다.)

## 챕터 이름 바꾸기

왼쪽 목차에서 **챕터 이름**을 **더블클릭**하면 수정할 수 있습니다.

1. 바꾸고 싶은 챕터 제목을 두 번 누릅니다.
2. 새 이름을 입력합니다.
3. `Enter` 또는 다른 곳을 클릭하면 저장됩니다. (`Esc`는 취소)

챕터·씬 행 높이는 일정하게 유지됩니다 (스크리브너처럼 클릭해도 간격이 벌어지지 않음).

## 챕터 순서 바꾸기 (드래그 앤 드롭)

왼쪽 목차에서 챕터를 끌어 순서를 바꿀 수 있습니다.

1. 챕터 제목 옆 **⋮⋮** 또는 챕터 줄을 누른 채 위·아래로 끕니다.
2. 원하는 위치에서 놓으면 순서가 저장됩니다.

## 본문 페이지 색 바꾸기

**본문(실제 글을 쓰는 칸)** 색만 바꿀 수 있습니다.
제목·도구 모음·통계·링크·헤더·좌우 패널 등 나머지 UI는 프로그램 기본 색을 유지합니다.

- 본문 칸에서 **오른쪽 클릭**, 또는 도구 모음의 **페이지 색**
- 아이보리 / 하얀색 / 연한 회색 / 세피아 / 민트 / 라벤더 / 다크 모드 / **칠판 모드**
- **직접 고르기…**

**칠판 모드**는 본문 기본 글자 색을 하얀색으로 바꾸고 안내 창을 띄웁니다.
글자 색은 도구 모음 **색**으로 수동 변경할 수 있습니다.

## AI 도움 (Gemini)

프로젝트 폴더의 `.env` 파일에 Gemini API 키를 넣으면 AI 글쓰기 도움을 쓸 수 있습니다.

```env
GEMINI_API_KEY=여기에_키
GEMINI_MODEL=gemini-flash-lite-latest
```

1. 상단 **AI 도움**을 누릅니다.
2. 방식 선택: 이어서 쓰기 / 문장 다듬기 / 회차 요약 / 투고·공모전용 시놉시스 / 아이디어 / 직접 요청
3. 필요하면 추가 요청을 적고 **AI에게 부탁하기**
4. 결과를 **원고 끝에 넣기** 또는 **복사**

`.env`는 비밀 파일이므로 다른 사람과 공유하거나 git에 올리지 마세요.
예시는 `.env.example`을 참고하세요.

## 설정집

왼쪽 바인더의 **설정집** 탭입니다. (원고 목차와 같은 패널에서 전환합니다.)

박스를 누르면 펼쳐지고, 접힌 상태에서는 내용의 **첫 두 줄 미리보기**가 보입니다.
박스를 **끌어** 순서를 바꿀 수 있습니다. (이 컴퓨터에 기억됩니다.)
각 박스 제목(메인 버튼)을 **우클릭**하면 그 기능을 잠시 숨길 수 있고, 관리자 모드에서 다시 켤 수 있습니다.

**기본 순서**

1. **생각 수첩** — 포스트잇 메모 (`+ 메모`, 메인에서 보드로 보기)
2. **작품소개·기획의도** — 한눈에 보는 소개와 쓰는 이유
3. **로그라인 / 줄거리 개요 / 시놉시스**
   - 로그라인: 한 줄 소개
   - **줄거리 개요**: 시작~결말 방향 (투고·공모 시놉시스 등에 참고)
   - 시놉시스: 작품 전체 줄거리
4. **키워드** — 장르·태그 칩 (목록에서 고르거나 직접 입력)
5. **세계관** — 시대·장소·규칙 등
6. **캐릭터** — 인물 목록·프로필·별칭·이미지 (메인 보드로 보기 가능)
7. **떡밥모음** — 심어 둔 복선·단서 (원고에서 문장 선택 → 떡밥 던지기, 회수 회차·알림)
8. **토리 수집창고** — 도우미 결과 등 모아 둔 메모
9. **참고자료/출처** — 링크·출처 메모

- 박스의 **→** 또는 **메인에서 보기**로 가운데 큰 화면에서 편집
- 바인더 **⟩** 로 접기, **⟨ 설정집** 탭으로 다시 열기
- 바인더 오른쪽 경계를 끌어 **너비 조절** (이 컴퓨터에 기억됩니다)

## 글자 수 · 목표 게이지

각 씬 하단에 원고 분량이 실시간으로 표시됩니다.

1. **집계 기준**을 고릅니다.
   - 공백 포함
   - 공백 제외
   - 단어 수
   - 글자 수 (문자·숫자·한글만, 기호·공백 제외)
2. **목표** 칸에 원하는 숫자를 적습니다.
3. 게이지 바로 진행률을 확인합니다.
4. **저장하기**를 누르면 목표와 기준이 함께 저장됩니다.

## 참고 링크

각 씬 하단에 **참고 링크**를 붙일 수 있습니다.

1. 씬을 연 뒤 **+ 링크 추가**를 누릅니다.
2. 제목과 주소(`https://...`)를 적습니다.
3. **열기**로 브라우저에서 바로 볼 수 있고, **저장하기**로 보관됩니다.

## 참고 이미지 / 동화 삽화

모든 작품 종류의 씬에서 **참고 이미지**를 넣을 수 있습니다.

1. 씬을 엽니다.
2. **+ 이미지 넣기**로 JPG/PNG/WEBP/GIF를 올립니다.
3. 필요하면 메모를 적고 **메모 저장** 또는 아래 **저장하기**를 누릅니다.

**동화** 작품에서는 같은 칸이 **동화 삽화**로 바뀌며, 추가로:

- **글 상자 추가**로 그림 위에 글을 쓸 수 있습니다
- 글 상자를 **끌어 옮기고**, **더블클릭**해 글을 씁니다

그림 파일은 `data/illustrations` 폴더에 저장됩니다.

## 글자 서식

원고 칸 위의 도구 모음으로 글자 모양을 바꿀 수 있습니다.

1. 바꾸고 싶은 글자를 드래그해 선택합니다.
2. 도구 모음에서 원하는 서식을 누릅니다.
   - **↩ 뒤로** 실행 취소 (`Ctrl+Z`)
   - **↪ 앞으로** 다시 실행 (`Ctrl+Y` 또는 `Ctrl+Shift+Z`)
   - **B** 굵게 (`Ctrl+B`)
   - **I** 기울임 (`Ctrl+I`)
   - **U** 밑줄 (`Ctrl+U`)
   - **정렬** 왼쪽 / 가운데 / 오른쪽
   - **1.** 번호 목록, **•** 글머리 목록
   - **글꼴** / **크기**
   - **색** 글자 색
   - **형광** 하이라이트 (색 고른 뒤 적용, 또는 형광 버튼)
   - **서식 지우기** 선택 구간의 서식 제거

기존에 써 둔 일반 텍스트도 그대로 열리고, 저장하면 서식(HTML)이 함께 보관됩니다.

## 함께보기 (두 회차를 같이 보기)

비교하고 싶은 회차가 두 개 이상 있을 때 쓸 수 있습니다.
기능바 **함께보기** 한 버튼에서 방식을 고릅니다.

1. 목차에서 먼저 회차 하나를 엽니다.
2. **함께보기 ▾** 을 누릅니다.
3. 원하는 방식을 고릅니다.
   - **화면 나누기** — 편집 화면 옆에 나란히 둡니다
   - **팝업으로 보기** — 떠 있는 창으로 참고합니다 (제목 줄을 끌어 이동, 모서리로 크기 조절)
4. 함께볼 회차는 목록에서 고를 수 있습니다.
5. 참고 중인 회차를 고치려면 **자유 편집**을 누르세요.
6. 패널 안의 **보기 방식**으로 나누기 ↔ 팝업을 바로 전환할 수 있습니다.
7. 끝낼 때는 메뉴의 **닫기**, 또는 패널 위 `×`를 누릅니다.

창을 닫고 싶으면 검은색 실행 창을 닫습니다. 다음에도 같은
`start_supertory.bat` 파일을 두 번 클릭하면 됩니다.

## 내 글 백업하기

앱을 먼저 닫은 뒤 `data` 폴더를 통째로 복사해 안전한 곳에 보관하세요.
그 안의 `supertory.sqlite3` 파일이 소설의 모든 글과 설정을 담고 있습니다.
